## Verification evidence

History GETs without cookies returned HTTP 200, CKAN success=true and CORS `*`. Both empty datasets for older control vehicles and populated odometer/ownership responses for a vehicle inside dataset coverage were observed. Raw plate-linked history responses stay local and are excluded from the public repository. Published history tests use synthetic inputs only. No engine serial, mileage or ownership history for a specific test vehicle is published in these documents.

Original VIN/tyre regression fixtures are retained from the original application. Browser verification is described in RELEASE.md.

## Valuation contract

There are **zero enabled automatic valuation providers**. Production never contains demo prices. The tested aggregator only accepts verified ILS estimates with a source URL, exact vehicle identity, valid current date (default maximum age 30 days), explicit basis, adjustment scope and methodology. It groups only matching method/basis/adjustments/source edition dates; deduplicates sources; preserves individual quotes. A single value remains single. Comparable range endpoints can combine. Different transaction/listing/reference/condition bases stay separate. Provider-specific verification and licensed field mapping must be implemented before enabling a provider.

## Technical-data gaps

No verified specifications for engine oil, coolant, brake fluid, gearbox oil, wiper lengths/mounting, alternative tyres, wheels/PCD/DIA/ET or load-specific pressures are connected. Only registered front/rear tyre sizes are connected. Gearbox identification is explicitly required; vehicle make/model/year are never used to guess the oil.
